# 追加42社のImageGen制作指示

Built-in ImageGenを使用し、`leads.csv`の09〜50番について各社のトップ画面と問い合わせ確認画面を1点ずつ生成した。元画像は`imagegen-originals/NN-home.png`と`NN-form.png`。メール用JPEGは`email-images/`に置く。

参考にした同業サイトは[豊進自動車サービス](https://www.houshin-j.com/)、[三ツ矢オートサービス](https://mitsuya-auto.com/)、[大八自動車](https://www.daihati8.co.jp/)、[ヨコヤマ自動車の予約ページ](https://yokoyama-ms.jp/reserve/) 。ヘッダー、工場写真、問い合わせ導線、情報カード、確認フォームという一般的な構成を参考にし、個別の写真、文章、ロゴ、配色、レイアウトは流用していない。

## トップ画面

各社名・所在地を入力し、16:9の日本語デスクトップLP画面案を独立して生成する。業種に合う架空の写真、読みやすいヘッダー、問い合わせ導線、3つの情報カードを含める。社ごとに配色と写真構図を変える。二輪業者にはバイクの整備写真を使う。`非公式の画面案・写真はイメージ`を明記する。電話番号、価格、評価、資格、未確認の個別サービス、実在の店舗写真やロゴは入れない。

## 問い合わせ確認画面

同じ会社のトップ画像を`referenced_image_paths`に渡し、配色・ヘッダー・写真の雰囲気を揃えて別途生成する。`お問い合わせ内容の確認`、`入力 → 確認 → 完了`、お問い合わせ内容・連絡方法・氏名・メールアドレス・電話番号の空欄確認行、`この内容で送信`と`入力に戻る`、`送信時点で依頼は確定しません`、`非公式の画面案・写真はイメージ`を指示する。実際の個人情報や連絡先は入れない。

生成画像内の細かな日本語や事業内容は正確性を保証しない。送信前に相手先ごとに画像を確認する。
